# Spurstate Website— Claude Context

## Project Overview
Spurstate is an AI solutions agency based in Auckland, New Zealand. This is the public-facing marketing website built with React 18 + TypeScript + Tailwind CSS v4 + Vite.

## Pages
- `/` — Home (hero, intro, Workdesk teaser, services overview, CTAs)
- `/about` — About & Mission (Spurstate story, who we serve, NZ focus)
- `/contact` — Contact page (book a call, get in touch, founder bio)
- `/workdesk` — Workdesk product page (features, stats, comparison, FAQ, beta CTA)
- `/download` — Download page (Mac/Windows installers via GitHub releases, getting started steps)

## Tech Stack
- React 18 + TypeScript
- Tailwind CSS v4 (via @tailwindcss/vite)
- React Router v6
- Lucide React (icons)
- Vite (build tool)

## Brand
- **Primary color:** Blue (blue-600 / blue-700)
- **Background:** White / gray-50 sections
- **Tone:** Bold, direct, plain-spoken. No buzzwords. Practical outcomes over features.
- **Target:** NZ business owners + primary school teachers

## Key Product: Workdesk
- Desktop app for NZ teachers (Mac + Windows)
- Generates lesson plans, unit plans, report comments via Claude AI
- Built around NZ Curriculum
- Privacy-first: nothing leaves the device
- Beta: seeking a small group of Auckland primary school teachers, free access

## What Spurstate Does
- AI adoption consulting — helping NZ businesses adopt AI to move faster and do more
- Workflow automation — rebuilding processes around AI so time is freed up
- Custom AI tools — purpose-built products for specific NZ professional contexts (Workdesk is the first)

Spurstate is NOT a marketing agency. Never reference Brand Strategy, Paid Advertising, or Social Media as Spurstate services.

## Do Not
- Use buzzwords: leverage, synergies, transformative, disruptive, innovative, cutting-edge
- Use passive voice
- Overclaim without specific proof points

## Key Proof Points
- NZ teachers work 47.5 hrs/week (2nd highest in OECD)
- Only 38% of time is actual teaching
- 7 hrs/week on lesson planning
- 150–300+ report comments per cycle, taking 15–30+ hours
- 56% of NZ teachers cite admin as major burnout source
